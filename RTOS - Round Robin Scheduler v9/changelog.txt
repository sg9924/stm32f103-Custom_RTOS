1: INITIAL
    - Kernel
        - Introduce PSP
        - Until now MSP was used by both the Kernel and the tasks
        - Now MSP is used only by the kernel
        - PSP is used only by the Tasks
        - rtosScheduler_Launch & PendSV_Handler have been modified
        - SVC_Handler IRQ Handler has been implemented which together with rtosScheduler_Launch launches the first task
    - Task
        - SCHEDULER_SWITCH_CONTEXT() Macro -> basically pends the Pend SV IRQ
        - original taskUnblock renamed to taskCheck_BlockedListTimeout
        - new taskUnblock unblocks a specific task provided by the caller through a task id
        - new: getTask_ByID -> gets a pointer to the TCB (Task) for the task id provided

2: Linker, Startup, Task, Kernel
    - Linker
        - Introduce user stack section to reserve some minimum space for stack
    - Startup
        - Introduce stack_watermark() to watermark the entire stack with 0xAAAAAAAA
        - Introduce stack_high_water_mark() to get the latest stack pointer value
    - Kernel
        - few corrections in rtosKernel_TaskStackInit
    - Task
        - Introduce pstack_base and modify stack_size_word from uint8_t to uint32_t in TCB
        - Assert for minimum stack size TASKSTACK_MINIMUM which is introduced in rtos_config.h
        - initialize pstack_base along with pstack
3: Cleanup
    - rename taskCheck_BlockedListTimeout to taskCheckAndUnblock
    - cleanup critical section enter and exit macros
